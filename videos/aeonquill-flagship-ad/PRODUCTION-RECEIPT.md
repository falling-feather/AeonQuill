# AEONQUILL 旗舰产品广告制作回执

- **成片目标**：26 秒，16:9；1920×1080 母版，1280×720 H.264/AAC 交付版。
- **当前状态**：五镜头主时间线、字幕、旁白、BGM、音效与四个跨镜转场已完成；最终 MP4 编码等待用户审片门确认。
- **真实产品素材**：项目中心、双层资源库、工作流中心、多智能体制片台、像素模式和当前应用图标均来自本机实际产品截图。
- **渲染方式**：HyperFrames 0.8.15 + 本地 GSAP 3.14.2，所有字体、图片和音频已冻结在项目内；镜头本身没有调用 MiniMax H3，也不会把 UI 动效伪称为 H3 生成视频。
- **音频方式**：Windows SAPI 5 离线普通话旁白；程序化 92 BPM 配乐；48 kHz 双声道总线；当前测得约 -14.8 LUFS。
- **检查结果**：`lint` 0 error；`check` 0 runtime/motion error；40/40 文本对比度满足 WCAG AA；四个转场均通过跨轨、重叠与双镜头引用验证；16 个全片关键帧及字体子集后的 5 个复核帧已人工检查。
- **可复现入口**：`index.html`、`STORYBOARD.md`、`audio_meta.json`、`.media/manifest.jsonl` 与 `compositions/frames/`。
- **待完成门禁**：用户选择“先看预览”或“直接渲染”后，编码并检查时长、分辨率、seek、黑帧、静帧、响度和文件哈希。

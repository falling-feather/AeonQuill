## 1. 目标与边界

从b082123检查点继续，完成本轮已有缺失能力和优化至可由用户验收的本机候选。暂不推送远端；不恢复项目对接、旧长期组或工作树。临时协助固定Luna/max，先设计任务/接口/写域，主开发集成。用户未提交的01排版和AGENTS保留。

已有六项媒体/质量任务继续沿用原编号。本轮增加像素低延迟、关联Cel、变换/剪贴板和Aseprite互通；均衡模式占位入口/效果链、LoRA配方/参考控制、跨媒体真实链和最终安装态分别盘点后在对应任务内落实。没有目标或数据的模型训练不启动；缺素材不制造toy训练或观感结论。

## 2. 实施顺序

1. 像素纯变换与ASE编解码可并行，写域与核心/界面隔离。主开发先处理保存时延，随后关联Cel迁移并接入UI。
2. 一次只完成一项独立可验收结果再提交；每个提交对应一个任务编号，01实现、02任务、03历史同步。
3. 检查当前模型/工具/数据，补风格角色LoRA导入、模型家族/哈希绑定、参考控制与配方复用。训练只有明确数据与设备前提时运行；可行性与缺口记录不得替代完整能力。
4. 在现有受管接口上完成图像、人物视频、声音与跨媒体全流程样本，逐项记录取消/恢复/局部返修与资产身份。单GPU任务串行，不中断用户GPU进程。
5. 最终执行相关定向、全量单元、默认、P7、性能门，clean提交封包并更新唯一App；逐次保护UserData和配置SHA，提交本机见证与验收清单。

## 4. 验收与持续工作

- 核心/边界先失败回归再实现；低风险机械项不写复述测试。
- 功能须有真实UI/服务链路；机器、主智能体视觉、真实模型执行与用户人工验收分开。
- 无新增付费外部调用；不以fixture推断模型效果，不为了关闭任务降级验收或隐去缺口。
- 原控制/资源预算保持；低延迟预算根据分项基线校准，未达到就继续优化或清楚记录实际资源上限。
- 用户离开期间持续推进独立工作。确实缺设备/数据/授权/人工材料时记录具体阻碍并处理其他任务，不能将单项阻碍等同整个项目结束。
- 交付前整理临时文件与修改过程痕迹；不重试此前已被执行器拒绝的同一删除，不清用户文件。

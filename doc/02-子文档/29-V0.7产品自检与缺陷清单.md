## 1. 审计结论

当前产品不是“整体不可用”：源码单元契约、类型、生产构建、确定性图片处理、隔离本机 API、桌面/窄屏浏览器烟测和 P7 六阶段集成全部通过。多项目、三模式入口、恢复点、均衡画布、像素绘制与交付、不可变资源跨模式取用、工作流安全导入、多智能体审批、内存 BYOK 和费用边界没有发现新的系统性回归。

但距离可对外承诺的完整商业产品仍有两类高优先级差距：

1. **当前手动测试的事实不够可信**：工作流中心误判共享模型缺失，正式 D 盘桌面又停留在 V0.7.18 构建，尚未包含源码 V0.7.20 的连续 H3 长片入口。用户看到的“缺失”与“最新版”都可能和真实状态不一致。
2. **若干入口只有管理壳、没有完整生产闭环**：自定义 ComfyUI JSON 能检查、导入和启用，但不能由生成入口选择执行；完整项目包仅覆盖均衡画布正文及其资产，没有统一携带像素/智能视频正文、生产状态和项目资源引用；部分语义图像工作流仍是模板待实现。

因此建议先修复“检测事实层”和“正式桌面同步”，再补齐自定义工作流、全项目迁移、语义编辑和视频角色/声音连续性。性能、诊断和商业发行门禁可在上述闭环稳定后并行推进。

## 4. 优化候选

以下内容不是本轮确认的阻断 Bug，但会决定产品是否从“功能较全的单机原型”成长为稳定创作工具。

### 4.1 均衡模式

- 把调整、裁剪、蒙版等非破坏性参数统一成可重排效果栈，生成式编辑继续创建不可变资产版本。
- 为图层、批量对齐、嵌套画框、复杂连接线、键盘焦点和大项目资源卸载建立专门压力门。
- 为语义编辑建立最小可复现实测集：商品、人物、毛发/半透明、文字海报和复杂遮挡，不只依赖视觉演示。

### 4.2 像素模式

当前已经有图层、非嵌套图层组、四种确定性混合、帧、洋葱皮、区域选择/变换、镜像绘制、撤销重做、图像转像素、Sprite Sheet、动画标签、正反/往返预览、批量帧时长、跨帧图层复制、逐帧锚点/碰撞区、8 邻域 Terrain 规则、调色板循环、片段内动画事件、活动片段包、确定性 3×3 Terrain 九宫格，以及同源八方向 manifest、Tiled TSJ/TMJ、离线查看器和 Godot/Unity/RPG Maker 单向桥接导出。下一步更有价值的是：

- 更细粒度的跨帧选区粘贴、任意尺寸地形笔刷和多 Terrain 场景编排。
- 在安装目标编辑器的固定兼容矩阵中运行 Godot/Unity/RPG Maker 导入模板，验证重复导入、运行时播放与往返一致性；双向回写另立冲突协议。
- 大尺寸、多帧、多图层的内存预算与 Worker 化渲染，避免浏览器主线程被长操作占用。

### 4.3 智能视频

- 将“角色圣经—服饰/场景状态—首尾/关键帧—H3 镜头—声音—剪辑”绑定为可追踪资产图，而不是主要靠提示词和上一镜末帧。
- 质量模式增加每镜自动候选、清晰度/身份/运动/字幕安全区评分和按失败原因定向重生；极速模式继续保持低步数预演。
- 把自定义 ComfyUI 工作流和外部 API 统一成同一种能力适配器，向用户展示显存、预计时间、预计费用、许可和可回退方案。
- 给长片提供时间线、镜头替换不重做全片、断点迁移、代理媒体和最终交付规格模板。

### 4.4 产品与商业发行

- 商业 Beta 前完成可信代码签名、分阶段更新/回滚、SBOM、模型/节点/API 许可证台账和干净 Windows 升级验收。
- 建立 Windows/NVIDIA 的明确兼容矩阵；RTX 4060 8GB 是当前实测基线，其他显卡、驱动、内存和系统版本不能由单机结果外推。
- 在真正计费前补齐账号/授权、订阅或买断、API 费用透传、内容安全、隐私说明、崩溃同意上报与离线许可策略。
- 用 5—10 名目标用户完成真实任务，记录首个可用资产时间、返修次数、任务成功率、单次成本和付费意愿，避免只按功能数量判断成熟度。

## 5. 建议顺序与验收门

建议下一轮讨论按以下顺序裁定，不在本审计中自动立项：

1. **事实层止血**：`AQ-WF-001`、`AQ-REL-001`、`AQ-WF-002`、`AQ-WF-003`。先让“装了什么、能不能运行、用户正在测哪一版”完全可信。
2. **数据与执行闭环**：`AQ-DATA-001`、`AQ-WF-004`、`AQ-STO-001`。先保证项目可带走、自定义能力真能跑、大文件不会失控。
3. **创作质量主线**：`AQ-IMG-001` 的功能纵切与 `AQ-VID-002` 的基础声音执行缺口已关闭；真实图像质量门转入 `AI-001`，随后继续 `AQ-VID-001`、语音强制对齐与长片声画增强，并选一个广告和一个人物叙事样片作为固定质量门。
4. **工程成熟度**：Job 保留、前端拆包、诊断包、兼容矩阵和商业发行门禁。

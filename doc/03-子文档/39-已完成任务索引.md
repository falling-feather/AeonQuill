1. 66 项状态为“已完成”的任务全部退出 02，并由本索引、[03-开发历史.md 第 3 节](../03-开发历史.md#3-独立提交记录)和历史阶段子文档共同承接。
2. 有独立 Git 提交的任务，以 03 主文档中的版本条目和提交标题为最终证据。
3. Git 建库前完成、后来整体进入 `V0.1.0` 初始快照的任务，仍只作为[未纳入提交历史的当前基线](../03-开发历史.md#4-未纳入提交历史的当前基线)登记，不伪造独立提交。
4. `FE-002`、`AI-001`、`AI-002`、`REL-002`、`PM-002` 尚未完成，继续留在 02；它们不属于本索引。

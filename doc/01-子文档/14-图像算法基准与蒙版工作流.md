## 1. 用户操作路径

```text
在均衡画布选中 image 元件
→ 打开图片实验室
→ 选择工具
→ 调整参数或绘制蒙版/点
→ 查看浏览器草稿或提交正式任务
→ 查看进度和错误
→ 接受结果
→ 画布创建/替换为新的不可变资产版本
```

图片实验室入口：`src/components/ImageLab.tsx`。前端算法：`src/lib/imageProcessing.ts`。服务调用：`src/lib/imageApi.ts`。

## 3. 浏览器草稿

`src/lib/imageProcessing.ts` 提供：

- 亮度、对比度、饱和度、色温等 filter 字符串。
- 裁剪与 cover/zoom 重采样。
- Bayer 4×4 抖动像素化预览。
- 浅色背景阈值去除预览。
- 2—4 倍浏览器放大预览。
- MaskRecipe 的低分辨率预览与正式尺寸渲染。

保护限制：

| 项目 | 限制 |
| --- | --- |
| 蒙版预览最大边 | 1024 |
| 蒙版正式输出最大像素 | 24000000 |
| 笔画数 | 512 |
| 总点数 | 20000 |

这些函数用于即时反馈；大图、模型处理和可追溯交付仍由服务端完成。

## 4. 确定性图像处理器

实现：`server/image-processor.mjs`，版本 `image-tools-v2`。

| operation | 参数 | 算法 |
| --- | --- | --- |
| `upscale-lanczos` | scale 1.5/2/3/4；sharpen 0—1.5 | Lanczos 缩放 + unsharp |
| `pixelate` | target 16/24/32/48/64/96/128/256；colors 2—64；output 1/2/4/8；dither；alpha | 最近邻缩小、palettegen/paletteuse、最近邻放大 |
| `sharpen` | radius 3/5/7；amount 0.1—2.5 | FFmpeg unsharp |
| `alpha-cleanup` | transparentBelow 0—127；opaqueAbove 128—255 | Alpha 分段重映射 |
| `masked-adjust` | effect；strength 0.1—1；feather 0—32 | 蒙版缩放/羽化后组合 |
| `remove-background` | model；alphaMatting；前后景阈值；erode 0—40 | rembg Python API |
| `upscale-realesrgan` | scale 2/3/4；model；tile 0—1024 | realesrgan-ncnn-vulkan |

`pixelate` 支持的 dither：

```text
none / bayer / floyd_steinberg / sierra2_4a / atkinson
```

`masked-adjust` 支持的效果由服务端注册表给出，当前包含 selection-highlight、background-dim、background-blur。前端不得自行发送未登记字符串。

全局输入限制：

- 单文件最大 20 MiB。
- 输入最大 40000000 像素。
- 输出最大 64000000 像素。

## 5. MaskRecipe v2

蒙版不是一张不可解释的临时 PNG；编辑意图保存为可重放配方：

```ts
type MaskRecipe = {
  schemaVersion: 2
  strokes: Array<{
    mode: 'remove' | 'restore'
    size: number
    points: Array<{ x: number; y: number }> // 归一化
  }>
  morphology: {
    expand: number   // -32—32
    feather: number  // 0—32
    trimWeakAlpha: number // 0—127
  }
}
```

生命周期：

```text
指针笔画 → 归一化点 → 内存预览
→ 保存 recipe → 按目标分辨率重放
→ 生成受管灰度/Alpha 蒙版
→ 正式任务消费该蒙版
```

schema v1 仅用于显式读取迁移。未知版本、点数超限、非法坐标或选区为空必须失败关闭。

## 6. ComfyUI 语义编辑

能力注册表：`server/semantic-workflow-registry.mjs`，版本 `semantic-image-v2`。

### 6.1 元素提取

| 属性 | 当前值 |
| --- | --- |
| ID | `element-extract` |
| 成熟度 | preview |
| 最低显存 | 4 GB |
| 依赖 | Impact Pack、SAM ViT-B、`SAMLoader` |
| 输入 | 源图、1—32 正向点、0—32 排除点、阈值 0.5—0.99 |
| 输出 | 透明元素、Alpha 蒙版 |

点坐标按图片归一化保存，因此缩放 UI 不改变语义位置。

### 6.2 区域编辑

| 属性 | 当前值 |
| --- | --- |
| ID | `region-edit` |
| 成熟度 | preview |
| 最低显存 | 8 GB |
| 依赖 | Qwen Image Edit 2511 INT8、Qwen 2.5 VL FP8、Qwen VAE |
| 输入 | 源图、蒙版、2—2000 字指令、seed、Alpha/Luma 通道 |
| 输出 | 编辑图 |

模型输出后再次用原始受管蒙版与源图合成；未选区域直接保留源像素，而不是依赖提示词“不要改背景”。

### 6.3 定点修改

`point-edit` 先用 SAM 将正负点编译成蒙版，再执行与区域编辑相同的 Qwen 工作流。输出同时保存编辑图和点选蒙版，便于重放与排错。超时预算 3900 秒。

### 6.4 人像调整

`portrait-adjust` 接受 2—1000 字指令和 0—1 身份强度。当前成熟度为 experimental；能执行不等于人物身份质量已经通过盲审。

## 7. 正式任务与资产版本

```text
选择源 image 元件
→ 解析当前项目可见 asset version
→ validateImageRequest / validateSemanticImageRequest
→ JobStore 创建 image 或 semantic job
→ Scheduler 取得 CPU/GPU
→ 执行器只读取受管输入
→ 临时文件输出
→ 探测尺寸/MIME
→ ProjectStore 内容寻址写入
→ 记录 parent version + operation + 参数摘要
→ 前端接受后回填画布
```

原图永不覆盖。重复内容按 SHA-256 复用二进制，但仍可形成不同逻辑版本和 provenance。

Data URL 只允许受限输入导入；不得把原始 Data URL、完整私有路径、来源 URL 或完整提示词写入公开 provenance。

## 8. 能力探测与失败

服务启动和用户刷新时探测：

- FFmpeg / ffprobe。
- Python 是否能导入 rembg。
- rembg 模型目录。
- Real-ESRGAN 可执行文件与模型对。
- ComfyUI 节点表与模型枚举。
- 当前 GPU/内存门。

能力不可用时 UI 保留工具说明但禁用正式提交，并给出缺失依赖。浏览器草稿若存在，可作为明确标记的替代预览，不冒充正式结果。

## 9. 新增算法的步骤

1. 定义稳定 operation ID、参数精确键、范围、资源类别和依赖。
2. 在前端工具注册表增加说明与参数面板。
3. 若有预览，实现低成本草稿并标记精度边界。
4. 在服务端验证所有字段，拒绝未知参数。
5. 通过 JobScheduler 执行；GPU 能力不得直接 spawn。
6. 只消费受管资产，输出先写临时文件再原子提升。
7. 记录算法/模型/工作流版本、参数摘要、父版本和输出哈希。
8. 增加尺寸上限、取消、超时、非法 MIME、输出缺失和重试测试。
9. 若是局部编辑，加入选区外像素漂移验证。

## 11. 当前限制

- SAM、Qwen 与 Real-ESRGAN 都不是主安装器内置能力。
- 语义编辑的协议纵切已经完成，但真实模型画质仍需固定素材基准。
- 浏览器白底去除不适合复杂头发、半透明物和非白背景。
- Lanczos 只做确定性插值；不能称为生成式超分。
- Qwen 人像调整当前为 experimental，不能承诺绝对身份保持。

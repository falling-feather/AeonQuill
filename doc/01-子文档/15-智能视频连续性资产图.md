## 1. 开箱状态

| 能力 | 开箱可用 | 条件 |
| --- | --- | --- |
| 灵感/剧本输入 | 是 | 无 |
| 场景、人物、地点、镜头拆分 | 是 | 本地确定性编译 |
| 十节点生产图 | 是 | 无 |
| 节点编辑、暂停、返修、审批 | 是 | 无 |
| 四个文本角色 Agent | 否 | 用户临时配置 OpenAI-compatible API |
| 图片/视频素材生成 | 否 | 安装并启用对应 ComfyUI 工作流 |
| H3 镜头 | 否 | H3 模型、节点、运行时通过复检 |
| 声音 | 部分 | 手动导入可用；TTS 需要 Adapter |
| 最终剪辑 | 有素材时可用 | FFmpeg + 已完成受管 Job |

智能视频不是“输入一句话后无条件自动出片”。它把全链路变成可保存、可干预、可恢复的生产状态机。

## 2. 用户完整流程

```text
项目中心
→ 新建智能视频项目
→ 输入灵感或剧本
→ 选择时长、类型、比例、极速/质量、快速/专业人物
→ 编译 StoryProject 与镜头
→ 进入制片生产图
→ 逐节点编辑、提交复核、批准
→ 绑定人物/服饰/场景/参考帧
→ 生成每个镜头的真实候选
→ 逐镜选择、评分、接受或定向重生
→ 声音字幕审批
→ 最终剪辑与质量报告
```

工作台有四个主区域：

| 区域 | 作用 |
| --- | --- |
| 制片 | 十节点生产图、督导、变更卡和审批 |
| 故事 | 灵感/剧本、场景、人物、地点 |
| 分镜 | 镜头顺序、时长、提示和参考帧策略 |
| 执行 | H3 参数、依赖清单、任务、候选和最终合成 |

入口文件：

- `src/modes/video/SmartVideoWorkbench.tsx`
- `src/modes/video/ProductionStudio.tsx`
- `src/lib/story/starterStory.ts`

## 3. 三层正文

`SmartVideoDocument schema v2` 组合三类事实：

| 层 | 主要对象 | 作用 |
| --- | --- | --- |
| 故事层 | `StoryProject` | 场景、镜头、人物、地点和剧本结构 |
| 生成层 | `GenerationPlan` | 每镜生成模式、比例、时长、提示词与参考策略 |
| 制片层 | `VideoProductionProject schema v5` | 十节点状态、变更卡、连续性、声音和审批 |

所有正文写入 WorkspaceStore，携带 base revision。浏览器 state 只是当前编辑镜像；刷新后必须从权威正文恢复。

## 4. 项目创建参数

| 参数 | 当前范围 | 行为 |
| --- | --- | --- |
| brief | 1—4000 字 | 创作目标 |
| durationMinutes | 1—30 | 目标总时长 |
| genre | 1—40 字 | 类型标签 |
| aspectRatio | 16:9 / 9:16 / 1:1 | 镜头与交付比例 |
| generationMode | fast / quality | 极速或质量 |
| characterMode | quick / professional | 快速立绘或专业连续性约束 |

`recommendProductionProfiles()` 根据体量、广告/电影质量信号和人物/剧情信号给出建议；用户仍可覆盖。

专业人物模式要求更完整的人物、服饰与场景变化记录，不意味着模型自动保证一致性。

## 6. 节点状态机

```text
waiting --依赖批准--> ready
ready --开始--> running
running --暂停--> paused
paused --恢复--> running
running --提交复核--> review
review --批准--> approved
review --要求返修--> revision
revision --开始--> running
任意可执行态 --失败--> failed
failed --重置--> ready 或 waiting
```

项目还支持全局 pause/resume。

规则：

- 节点输出编辑会产生新 revision。
- 修改已批准的上游会使依赖它的下游产物失效。
- 批准是人工动作；督导和模型不能代替。
- 节点事件最多 200，变更卡最多 80。
- 单节点输出最多 12000 字，单指令最多 4000 字。

命令定义在 `productionPipeline.mjs`，包括 project、node、proposal、continuity 和 sound 命令族。

## 7. 本地督导与文本 Agent

### 7.1 确定性督导

`src/lib/story/videoSupervisor.mjs` 每轮从当前生产图推导一个状态：

- 下一可执行节点。
- 等待用户审批。
- 被暂停。
- 被依赖阻断。
- 需要真实媒体。
- 已完成或失败。

督导本身不保存第二套 session，不跨节点推进，也不伪造素材。

### 7.2 可选文本 Agent

只允许四个文本节点使用模型：

```text
screenwriter / character-designer / art-director / storyboard-director
```

服务端 `server/video-supervisor.mjs` 重新读取 WorkspaceStore，只为当前节点形成一个 `video.node.edit` 计划。共享编译层在 `server/agent-plan-composer.mjs`。

BYOK 边界：

- API Key 只在 sidecar 内存。
- 外部 endpoint 必须 HTTPS；HTTP 仅允许回环。
- 请求使用有界、脱敏的正文摘要。
- 响应必须是严格 JSON 结构。
- 模型只能提议变更卡，用户批准后才写入。
- 素材、H3、声音、剪辑和质检节点不会被文本响应冒充完成。

## 8. 连续性资产图

`VideoContinuityGraph schema v2` 保存：

- 角色身份资产。
- 服饰版本与场景分配。
- 地点/场景资产。
- 镜头首帧和末帧。
- 镜头真实视频候选。
- 当前选择和人工复核历史。

资产绑定：

```text
从资源库选择版本
→ 校验项目可见性、MIME、SHA-256
→ 写 continuity binding
→ 人工批准
→ 执行清单引用精确版本
```

解除绑定不会删除资源库原件，只使依赖它的执行输入失效。

## 9. 镜头候选与人工复核

候选必须是当前项目可见的真实 MP4/WebM 不可变版本。每个候选记录：

- candidate ID。
- shot ID。
- library item/version。
- content hash、MIME。
- 来源 Job 和执行 identity。
- 输入 fingerprint。
- 登记时间。

规则：

1. 登记候选不自动选中。
2. 选择新候选会使旧活跃结论 superseded，但保留历史。
3. 人工复核必须绑定 candidate ID。
4. 提示词、参考帧、人物/服饰/场景约束变化会改变 input fingerprint。
5. fingerprint 过期的候选不能作为当前通过结论。
6. 定向重生创建新 Job 与候选，不覆盖旧视频。

人工评分可覆盖身份、服饰、场景、清晰度、运动、连续性等维度；机器检查不能替代人物观感。

## 10. 执行清单与确认摘要

真正提交前生成运行时快照：

```text
项目 ID + Workspace revision
+ 镜头与 generation mode
+ prompt digest
+ 首/尾帧 asset version + SHA
+ preset/profile/workflow version
+ ComfyUI/节点/模型状态
+ 输出策略
```

系统对规范化清单计算摘要。用户确认绑定该摘要；任何字段变化都会使确认失效，必须重新检查。

提交后服务端再次读取当前正文和资产，不信任前端旧快照。

## 11. 连续长片与最终剪辑

`video-chain` 的父 Job 只编排，不占 GPU：

```text
shot 1: T2V 或显式 I2V
→ 完成并写入受管 MP4
→ 服务端提取真实末帧
→ shot 2: I2V
→ 重复
→ 已完成子 Job 断点可复用
→ final-cut 只消费完成 Job ID
```

最终剪辑：

- 不接受任意本机路径。
- 不覆盖源镜头。
- 输出固定质量报告与交付副本。
- 中断重试可复用仍然可读的 completed 子任务。
- 旧镜头候选保留，便于回退。

相关文件：

- `src/lib/story/videoChainManifest.mjs`
- `server/local-video-candidate.mjs`
- `server/video-finalizer.mjs`
- `server/video-delivery-quality.mjs`

## 14. 当前限制

- 默认示例剧本用于展示，不代表新项目已经完成创作。
- 文本 Agent 只覆盖四类文本节点，不是无人值守多媒体 Agent。
- 真实人物一致性、双人交互和长镜头质量仍需固定样片盲审。
- 快速/专业人物模式目前主要改变规划与约束深度，不是两套独立基础模型。
- 生产图最多 30 分钟目标时长；更长内容应拆为多个项目或章节。

> 4. 既有历史不因后续修改、清理或回滚删除。

## 2. 大版本与中版本汇总

### 2.1 V0.1 可追踪原型基线

- **日期范围**：2026-08-14
- **原定目标**：在不伪造旧提交的前提下，把现有单机创作原型建立为可恢复、可分支和可远端协作的基线。
- **实际结果**：初始化 `main`，建立安全忽略边界，创建并绑定 GitHub private 仓库 `falling-feather/AeonQuill`；登记 AEONQUILL 品牌、长期工作组和隔离工作树；完成语义元素提取、像素模式、智能视频计划、品牌主页及三模式主线接入。
- **包含小版本**：V0.1.0、V0.1.1、V0.1.2、V0.1.3、V0.1.4、V0.1.5、V0.1.6

### 2.2 V0.2 原型完善周期

- **日期范围**：2026-08-14—2026-08-15
- **原定目标**：把三模式首轮页面与内核纵切推进成可连续演示、可恢复、可导出、失败可解释并通过独立验收的单机原型。
- **实际结果**：统一产品壳与恢复、均衡模式语义局部编辑、像素资产生产、智能视频计划执行四条纵向链路全部完成；`QA-002` 独立覆盖桌面/窄屏、深链与错误恢复、不可变派生、像素成套下载与配额降级、智能视频 ready/blocked 和受控队列、安全与生命周期。QA 在 `V0.2.6` 发现桥接重启后 SSE 终止的 P1，`DEV-011` 修复后于 `V0.2.7` 同条件复测通过，最终结论为“通过”。该结果只代表单机原型周期退出，不代表商业系统或 Stage B 完成。
- **包含小版本**：V0.2.0、V0.2.1、V0.2.2、V0.2.3、V0.2.4、V0.2.5、V0.2.6、V0.2.7、V0.2.8

### 2.3 V0.3 阶段软件封包周期

- **日期范围**：2026-08-15
- **原定目标**：把 `V0.2.8` 单机原型推进为可交给个人用户试装的 Windows x64 软件包，完成 AEONQUILL 品牌、自包含桥接、数据隔离、依赖诊断、图像/视频能力接线、发布物料和独立安装验收。
- **实际结果**：锁定里程碑、包体与外部依赖边界、实施波次和完成矩阵；`DEV-012` 实现当前用户 data/runtime/cache/log/config 分层、严格本机配置、有界 ComfyUI 发现、聚合诊断、设置页面和跨随机 Origin 恢复；`REL-003` 统一 AEONQUILL 发行身份，完成自包含 Node 22 sidecar、当前用户 NSIS、受控 staging、严格 manifest/SHA-256、Electron 回退壳和隔离安装—启动—卸载自检。`QA-003` 首轮发现新 H3 产物仍使用旧品牌，第二轮确认真实关闭主窗口后 desktop、sidecar 与端口后台驻留；`DEV-013`、`DEV-014` 分别修复后，第三轮从 V0.3.4 干净源码构建的唯一候选通过安装、真实 FFmpeg、跨端口恢复、SSE、安全、真实 `WM_CLOSE`、卸载与完整门禁。周期以“阶段测试安装包通过”退出，不代表商业发行或 Stage B/D 完成。

### 2.4 V0.4 完整离线运行时封包周期

- **日期范围**：2026-08-20—2026-08-21
- **原定目标**：修复用户在 V0.3 APP 图生视频中发现的固定工作流 JSON `ENOENT`，替换用户提供的应用图标，并让 Windows x64 阶段包不依赖系统 Node/Python 或用户手工配置外部 ComfyUI 即可执行图像与固定 H3 视频任务。
- **实际结果**：`REL-004` 把 T2V/I2V 模板纳入 sidecar 资源闭包和启动前预检，生成“时钟、砚台与画笔”全套图标，并建立固定 ComfyUI 0.30.2、Python 3.12.10、Torch 2.8.0+cu129、节点、模型和图片工具运行时；packaged sidecar、staged ComfyUI、FFmpeg/rembg/Real-ESRGAN 和真实 T2V/I2V 均通过。`REL-005` 建立 D 盘 `App`/`UserData` 便携布局并迁移既有用户数据，`REL-006` 修复迁移幂等边界，`REL-007` 将 WebView2 profile 与后续 Tauri 构建缓存一并收束到 D 盘。V0.4.3 最终安装器、完整包、隔离安装与真实 D 盘替换均通过。`DEV-015` 在不改动 50.28 GiB 运行时的前提下完成 V0.4.4 体验维护；`REL-008` 随后从干净提交生成 0.4.5 安装器，完成 D 盘隔离安装—启动—卸载、真实应用替换、数据保留、唯一快捷方式和安装态隐藏生命周期验证。V0.4 以未签名本机阶段包完成退出。
- **包含小版本**：V0.4.0、V0.4.1、V0.4.2、V0.4.3、V0.4.4、V0.4.5、V0.4.6

### 2.5 V0.5：H3 多场景与画布框选修复

- **日期范围**：2026-08-22
- **原定目标**：把 MiniMax H3 从单一测试模板扩展为面向 RTX 4060 8GB 的多场景、可分档、可编译提示词的视频主路径，并修复用户发现的无限画布框选预览坐标错误。
- **实际结果**：建立六场景工作流、FP8 主路径、4/6/8 步档位、提示词编排和显存降档；真实完成 T2V 720P 与 I2V。随后把框选预览从错误的视口左上锚定改为画布世界坐标与选择几何一致，并完成 0.5.0、0.5.1 两轮 D 盘桌面实装。
- **包含小版本**：V0.5.0、V0.5.1、V0.5.2、V0.5.3、V0.5.4、V0.5.5

### 2.6 V0.6：高质量视频、完整运行时与专业创作

- **日期范围**：2026-08-23—2026-08-24
- **原定目标**：在 RTX 4060 8GB 上用更长耗时换取可用的 720P 视频质量，建立可搬迁完整运行时，并把像素与智能视频从第一纵切推进到专业工作台。
- **实际结果**：建立 H3 Base 20 步母版、SeedVR2 3B INT8 时序精修和六档质量矩阵；形成 cu130 Python/ComfyUI/节点/模型完整闭包及测试自签名发行链。像素模式补齐专业绘制与区域变换；智能视频建立可暂停、审批、返工的十节点多智能体生产链；QA 修复源码测试发现范围。
- **包含小版本**：V0.6.0—V0.6.16

### 2.7 V0.7：项目平台、智能创作与产品自检

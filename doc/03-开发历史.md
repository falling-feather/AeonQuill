## 2. 大版本与中版本汇总

### 2.1 V0.1 可追踪原型基线

- **日期范围**：2026-08-14
- **原定目标**：在不伪造旧提交的前提下，把现有单机创作原型建立为可恢复、可分支和可远端协作的基线。
- **实际结果**：初始化 `main`，建立安全忽略边界，创建并绑定 GitHub private 仓库 `falling-feather/AeonQuill`；登记 AEONQUILL 品牌、长期工作组和隔离工作树；完成语义元素提取、像素模式、智能视频计划、品牌主页及三模式主线接入。
- **包含小版本**：V0.1.0、V0.1.1、V0.1.2、V0.1.3、V0.1.4、V0.1.5、V0.1.6

### 2.2 V0.2 原型完善周期

- **日期范围**：2026-08-14—进行中
- **原定目标**：把三模式首轮页面与内核纵切推进成可连续演示、可恢复、可导出、失败可解释并通过独立验收的单机原型。
- **实际结果**：已锁定统一产品壳与恢复、均衡模式语义局部编辑、像素资产生产、智能视频计划执行四条纵向链路，登记实现任务、长期工作组、范围外内容、共享架构边界和独立 QA 退出门禁；均衡模式已完成 `SAM → Alpha 派生图 → 确定性区域调整 → 新版本 → 重载恢复`，统一产品壳恢复链已完成开发级验证，智能视频已建立严格清单、受控 H3 映射、内容哈希和既有 Job/SSE 接线，像素模式也已形成 PNG/WebP 确定性转换、人工修正、无污染动画预览及项目/资产成套往返；主线联调与独立 QA 仍在进行中。
- **包含小版本**：V0.2.0、V0.2.1、V0.2.2、V0.2.3、V0.2.4、V0.2.5
